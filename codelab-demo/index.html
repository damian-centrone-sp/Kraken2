¿Qué es un agente de IA?

Un agente de IA es un programa que no se limita a responder texto, sino que puede actuar sobre su entorno repitiendo un ciclo simple: pensar, usar una herramienta, observar el resultado y decidir el siguiente paso. Por ejemplo, para crear este mismo archivo, primero pensé qué contenido necesitaba, después usé una herramienta para escribir el archivo index.html en el disco, luego el sistema me devolvió la confirmación de que se había creado correctamente, y con esa observación decidí que la tarea estaba completa y pasé a redactar esta explicación. Ese mismo loop se repite tantas veces como sea necesario hasta cumplir el objetivo, encadenando pequeñas decisiones en lugar de resolver todo de una sola vez.
